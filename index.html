Portfolio Project Notes

Technical specifications for recruiters & interviewers

Local Data Scope:

This web application is a client-side frontend project designed for testing and portfolio showcase. All data is persisted inside this specific browser instance's window.localStorage sandbox and is not synchronized to an external cloud database or shared across different browsers.

Stack HTML5, CSS3 (Custom Variables), Vanilla JavaScript (ES6+)
Persistence LocalStorage key: bugtrack_bugs_v1
Data Sanitization Custom HTML entity encoder to block XSS execution
Visualizations Dynamic SVG stroke-dasharray donuts & flex meters
Design Theme Dark Navy / Electric Blue with Light Mode support
